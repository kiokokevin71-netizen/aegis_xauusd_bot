# AEGIS-XAUUSD // Dedicated Gold Autonomous Trading Bot

Locked strictly to **XAUUSD (Gold)** with a gold-themed Streamlit dashboard, fixing authorization error `[-6]` and resolving MT5 socket handshakes.

## Quick Start (Windows PowerShell)
1. Ensure MetaTrader 5 is open and logged into your account.
2. Run:
   ```powershell
   Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
   .\deploy.ps1
   ```
3. Enter your correct MT5 login ID and master password in the **Settings** tab.
